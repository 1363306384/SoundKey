# SoundKey 1.0.3

[English](1.0.3.md) · **简体中文**

## Mac 与 Windows 更新

- **快捷键总览**：通过「曲库 → 快捷键总览」集中查看分组绑定，修改、清除按键或定位音乐。浏览、修改其他分组不会切换当前播放分组，冲突时保留原绑定。
- **固定完整键盘图**：绑定列表独立滚动，键盘始终完整显示。Mac 按紧凑 ANSI 苹果键盘排列，包含宽空格、Fn／地球键、修饰键和倒 T 方向键；Windows 使用对应键盘布局。支持修饰键组合筛选，无法保证检测系统或其他软件的占用。
- **单击选中、双击播放**：选中其他行不会改变底部正在播放的曲名、状态和进度。底部播放／暂停始终控制实际播放的音乐，停止后可重新播放最近播放的曲目。空格保留原有控制所选曲目的行为。
- **播放器布局**：播放控件居中，循环、速度与音量集中排列，较窄窗口使用紧凑布局。
- 修复缺失音频文件记录无法移除的问题；Windows Ctrl+O 优先遵守已绑定的音乐快捷键。
- 完善曲目选择、播放操作的辅助功能。
