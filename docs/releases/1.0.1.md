## Windows improvements

- A **Library** menu groups backup/restore and Recently Deleted, matching the Mac workflow.
- The header, brand subtitle, action order, track numbering, playback hints and seek icons use a more consistent hierarchy.
- **Manage Groups** opens an overview for creating, renaming, switching and removing empty groups. Track order remains draggable; group order is not editable.
- YouTube search and link import open separate windows instead of sharing tabs. Search stays available during an active download, and closing a window leaves the download running.
- Settings are streamlined around language, the music shortcut switch and global shortcut status.
- Setup, uninstall, file descriptions and newly created shortcuts use English. The upgrade removes only known old Chinese shortcut entries while preserving the local library and settings.

The app itself retains immediate English/Chinese language switching. Existing music, groups, playback ranges and shortcut assignments are preserved when updating; export a backup first.

## Signing and verification limits

The Mac app uses an **Apple Development** signature. Its Installer package is unsigned, and this release is **not notarized by Apple**. Run the included **安装SoundKey.command**, read its notice, type **INSTALL**, and complete the system Installer. Manual macOS approval may still be required.

The Windows app and installer remain **unsigned**. Windows signing needs a trusted code-signing identity; a valid signature would not guarantee immediate SmartScreen reputation. See the [Windows signing FAQ](../installation.md#can-the-windows-app-be-signed).

### Verification scope

Representative checks on one Windows computer covered:

- The actual installer's welcome, directory, installation and finish pages were in English; installation completed and the app launched.
- The existing library, group, shortcut binding and master volume were retained. Settings showed only **1.0.1**, and English → Chinese → English switching worked.
- Library backup, an empty Recently Deleted list, and the group overview opened and closed correctly. No backup, restore or group-edit operation was run as part of this check.
- Link import and YouTube search opened as separate windows. A live YouTube query returned results; no audio was downloaded.
- Play/pause and advancing playback progress were observed. A bound key started playback while the desktop had focus, and Stop reset progress. Audible output quality was not assessed.

Full uninstall, real legacy-shortcut migration, a high-DPI test matrix and general Windows 10 compatibility were not exercised. These representative checks do not establish every supported device or configuration. The other Mac's first Input Monitoring **Quit & Reopen** flow also remains unverified.

Download the named **.dmg** or **Setup.exe** installer for the application. GitHub's generated ZIP/TAR archives contain this documentation repository only, not SoundKey application source code.
