## Included

- Local audio import with a saved library copy, team groups and per-track shortcuts.
- Playback ranges, track ordering, playback modes, speed and master volume.
- Full-library backup/restore and Recently Deleted recovery.
- YouTube search, preview in your browser and single-link audio import.
- English and Chinese interfaces with immediate language switching.

## Refined for 1.0.0

- Clearer first-use, playback and shortcut guidance, with version-only display in Settings and About.
- A single small native Mac loading indicator and simpler progress cards; no duplicate spinning import button.
- Better distinction between inactive Input Monitoring and an unavailable background listener; Mac settings and permission information windows allow normal app exit.
- Playback controls remain useful when a different selected track is removed or moved.
- More reliable shortcut capture and Windows drag ordering.
- Import cancellation reflects the current phase, and a running download keeps its original destination group.

## Signing and verification

The Mac application has an **Apple Development** signature. The Installer package is unsigned and the release is **not notarized**. Use the included **安装SoundKey.command**, read the notice, type **INSTALL**, and complete Apple's Installer. Manual macOS approval may still be needed.

The Windows application and installer are **not Authenticode-signed**. Windows may show an unknown-publisher or SmartScreen notice.

Mac passed 24 regression suites, deep signature and package integrity checks, plus local native checks of layout, version display, normal exit/reopen and import cancellation. Windows passed the current business-logic checks, release build and installer payload/integrity audit.

The first-permission **Quit & Reopen** cycle and full downloaded installation flow on the other macOS 15.2 machine remain unverified. Windows installation, audio, interface and global-keyboard-hook behavior still need native Windows testing.

Existing local music and settings are retained when updating. Export a library backup before updating. Online availability depends on the source site; sign-in, VIP/paywalled content and playlists are outside the supported import workflow.
