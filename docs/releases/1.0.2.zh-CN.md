## Mac 与 Windows 共同更新

- **后台批量导入：**文件检查与复制在后台执行，显示进度并支持取消；期间可继续播放、搜索、调音量和切换分组。音乐仍加入开始导入时选定的分组。重复音乐可选择跳过、仍然导入、查看已有歌曲，或取消整批。最终保存前取消会撤回本批导入；最终保存作为一个完整操作完成。修改曲库、备份和恢复需等导入结束。
- **暂停／继续快捷键：**默认按 **M** 暂停或继续当前音乐，可在「设置 → 快捷键」中修改或清除。它不会从停止状态开始播放。若已有歌曲使用 M，升级时保留歌曲绑定，请另设暂停键。暂停键不能与任何分组的歌曲按键冲突。
- **本地 MP4 转 MP3：**打开「曲库 → 本地 MP4 转 MP3」，选择本地 MP4 和保存位置，离线提取第一个音轨为 **192 kbps MP3**，保留原 MP4。转换显示进度并可取消，覆盖已有目标前需要确认，失败或取消会清理临时输出。需要加入曲库时，再导入保存好的 MP3。
- **播放响应优化：**进度更新避免刷新整个曲库，拖动音量时避免反复保存曲库。大曲库和导入检查针对响应表现，不代表所有场景的 CPU 占用或整批导入总耗时都会降低。

## Windows 界面对齐

主标题栏、曲库菜单、分组选择器、快捷键状态、搜索、音乐行、播放器、共用样式和对话框操作顺序以 Mac 为基准。分组总览直接重命名并保存／取消；音乐移到「最近删除」前先确认；输入框内边距、操作菜单对齐和焦点处理进一步完善。

备份、恢复与最近删除采用对应的信息层次。「搜索 YouTube」与「从链接导入音乐」保持独立窗口，重新打开时保留搜索关键词和可用结果；关闭会取消搜索，正在进行的下载继续。

系统窗口控件、文件选择器、字体、按键名称和后台快捷键权限保留平台原生行为。共用布局值不表示不同系统或缩放比例下的文字可以逐像素相同。

## 安装与已有曲库

Mac 安装入口改为 **Install SoundKey.command**，文件名、欢迎页、终端提示和安装错误提示均为英文。Windows 安装与卸载向导继续使用英文；两端应用内仍可即时切换中英文。

更新保留单独存放的音乐曲库、分组、绑定和设置。更新前请从「曲库 → 曲库备份与恢复」导出备份。Windows 创建桌面和开始菜单快捷方式；Mac 从「应用程序」打开。

## 签名

Mac 应用使用 **Apple Development** 开发签名；Installer 安装包未签名，发行包仍未经过 Apple 公证。请运行包内 **Install SoundKey.command**，阅读提示后输入 **INSTALL**，再在系统安装器中完成安装。macOS 仍可能要求手动确认。

Windows 应用和安装器仍**未签名**。当前签名状态与系统提示见[安装指南](../installation.zh-CN.md)。
