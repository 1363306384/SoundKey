# SoundKey 1.0.0

[English](1.0.0.md) · **简体中文**

面向 Mac 和 Windows 的音乐快捷键工具。把音乐整理到分组，绑定按键，直接播放想要的音乐或片段。

## 主要功能

- 本地音乐导入并保存副本，按团队分组整理，为每首音乐绑定快捷键。
- 播放片段、音乐排序、播放模式、速度与总音量。
- 完整曲库备份与恢复，以及「最近删除」找回音乐。
- YouTube 搜索、浏览器试听和单链接音频导入。
- 英文与中文界面，即时切换语言。

## 1.0.0 优化

- 优化首次使用、播放与快捷键提示，设置和「关于」只显示版本号。
- Mac 使用单个小型系统加载指示器和简洁进度区，导入按钮不再重复旋转。
- 区分输入监控尚未生效与后台监听不可用；Mac 设置和权限说明窗口允许正常退出应用。
- 移除或移动其他已选音乐后，仍能控制当前播放。
- 改进快捷键录制与 Windows 拖动排序。
- 取消下载与实际阶段保持一致，正在运行的导入任务保留原目标分组。

## 签名与验证情况

Mac 应用使用 **Apple Development 开发签名**，Installer 安装包未签名，发行包**尚未经过 Apple 公证**。请运行包内 **安装SoundKey.command**，阅读提示后输入 **INSTALL**，再在 Apple 系统安装器中完成安装。macOS 仍可能要求手动确认。

Windows 应用与安装器**尚无 Authenticode 发行签名**，可能显示未知发布者或 SmartScreen 提示。

Mac 已通过 24 项回归、深度签名与安装包完整性检查，并在本机核对了界面、版本显示、正常退出／重开以及导入取消流程。Windows 已通过当前业务逻辑检查、发行构建与安装包内容／完整性审计。

另一台 macOS 15.2 电脑首次授权时的「退出并重新打开」及完整下载安装流程尚未验证；Windows 安装、音频、界面和全局键盘监听仍需原生 Windows 实机测试。

更新会保留现有本地音乐和设置，更新前建议先导出曲库备份。在线内容能否导入取决于来源网站；当前导入流程不支持登录、VIP／付费内容或整份播放列表。
