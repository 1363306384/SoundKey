## Windows 改进

- 「曲库」菜单集中提供备份／恢复和最近删除，与 Mac 流程对应。
- 统一主界面的品牌副标题、工具顺序、音乐序号、播放提示和前后跳转图标，改善信息层次。
- 「管理分组」打开分组总览，可新建、重命名、切换分组和删除空分组。音乐可拖动排序，分组顺序目前不可调整。
- YouTube 搜索与链接导入分别打开独立窗口，不再合并为标签页；下载期间仍可继续搜索，关闭窗口后下载继续。
- 设置围绕语言、音乐快捷键总开关和后台快捷键状态整理。
- 安装、卸载、文件说明和新建快捷方式统一使用英文；升级仅清理已知旧版中文快捷方式，保留本地曲库和设置。

应用内仍支持即时切换中英文。更新保留已有音乐、分组、播放片段和快捷键绑定，更新前建议导出曲库备份。

## 签名与验证范围

Mac 应用使用 Apple Development 开发签名，Installer 安装包未签名，发行包仍未经过 Apple 公证。请运行包内 **安装SoundKey.command**，阅读提示后输入 **INSTALL**，再在系统安装器中完成安装。macOS 仍可能要求手动确认。

Windows 应用和安装器仍未签名。Windows 发行签名需要受信任的代码签名身份；有效签名也不保证立即获得 SmartScreen 信誉，详见[Windows 签名问答](../installation.zh-CN.md#windows-可以签名吗)。

### 验证范围

已在一台 Windows 电脑完成以下代表性检查：

- 实际安装器的欢迎、目录、安装和完成页面均使用英文，安装完成后应用可以启动。
- 已有曲库、分组、快捷键绑定和总音量得到保留。设置仅显示 **1.0.1**，英文 → 中文 → 英文切换正常。
- 曲库备份窗口、空的「最近删除」列表和分组总览均能打开与关闭；本次没有执行备份、恢复或分组编辑操作。
- 链接导入和 YouTube 搜索分别打开独立窗口；真实 YouTube 查询返回结果，没有下载音频。
- 已观察播放／暂停及进度推进，桌面处于前台时绑定键能触发播放，停止后进度归零；没有评估可听输出的音质。

完整卸载、旧快捷方式的真实迁移、多种高 DPI 设置和 Windows 10 的一般兼容性尚未测试，以上代表性检查不覆盖所有设备与配置。另一台 Mac 首次输入监控授权后的「退出并重新打开」流程也仍待实机验证。

应用请下载具名的 **.dmg** 或 **Setup.exe** 安装包。GitHub 自动生成的 ZIP/TAR 只包含本仓库介绍与文档，不含 SoundKey 程序源码。
