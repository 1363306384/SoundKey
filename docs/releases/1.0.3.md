# SoundKey 1.0.3

**English** · [简体中文](1.0.3.zh-CN.md)

## Changes on Mac and Windows

- **Shortcut Overview:** open Library → Shortcut Overview to review a group's bindings, edit or clear a shortcut, and locate its track. Browsing and editing another group keep the current playback group. Duplicate bindings are rejected without discarding existing settings.
- **Fixed keyboard diagram:** the complete keyboard stays visible while the binding list scrolls. Mac uses a compact ANSI Apple layout with a wide space bar, Fn / Globe, modifiers and inverted-T arrows; Windows uses its own keyboard layout. Modifier filters show combinations. Other apps' shortcut occupancy cannot be guaranteed.
- **Click to select, double-click to play:** selecting another row leaves the bottom player's title, state and progress on the track actually playing. The bottom play/pause button controls that track; after stopping it can replay the last played track. Space retains its documented selected-track behavior.
- **Player layout:** central playback controls, grouped repeat/speed/volume controls, and compact handling at narrower widths.
- Missing audio-file records can be removed without deleting unrelated files. Windows Ctrl+O respects an assigned music shortcut.
- Improved accessibility for track selection and playback actions.
