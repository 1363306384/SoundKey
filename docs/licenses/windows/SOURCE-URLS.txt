SoundKey 1.0.0 — Windows third-party tool sources

These upstream command-line tools are invoked as separate processes.
Bundled tools: yt-dlp (standalone onedir), FFmpeg, and Deno.
No standalone FFprobe executable is included in SoundKey 1.0.0.
Original upstream executable bytes are retained; the _internal folder accompanies yt-dlp.
Upstream archive hashes identify the download, not the complete SoundKey installer.
