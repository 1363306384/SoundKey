SoundKey 1.0.0 — macOS third-party tool sources

These upstream command-line tools are invoked as separate processes.
Bundled tools: yt-dlp (standalone onedir), FFmpeg, and Deno.
No standalone FFprobe executable is included in SoundKey 1.0.0.
The macOS package narrows universal binaries to arm64 and adds code signatures.
Upstream archive hashes identify the download, not the final signed installer.
