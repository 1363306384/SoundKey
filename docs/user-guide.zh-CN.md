# SoundKey 用户指南

[English](user-guide.md) · **简体中文** · [返回首页](../README.zh-CN.md)

SoundKey 按分组整理音乐，支持用单个按键或组合键直接播放。可以先用鼠标播放，稍后再设置快捷键。Mac 与 Windows 采用相同的内容布局、操作顺序和对话框流程；窗口控件、文件选择器、按键名称与后台权限设置保留各平台原生行为。

## 播放第一首音乐

1. 点击「导入本地音乐」，选择音频文件。可以先用 MP3、M4A、WAV；其他格式能否播放取决于平台音频支持。
2. 单击音乐行仅选中，双击播放。底部始终显示和控制最近实际播放的音乐，不随选中变化；音乐左侧的小播放按钮也可以直接播放该曲。
3. 点击「设置快捷键」，按下想绑定的按键或组合键并保存。
4. 保持「音乐快捷键总开关」开启。Mac 如需在其他软件中使用绑定键，还需完成[输入监控授权](installation.zh-CN.md#在其他软件中使用快捷键)。

导入时会把音频复制到本地曲库，之后移动原文件不会影响已导入的副本。

批量导入会在后台检查和复制文件，主界面显示进度，可继续播放、搜索、调音量或切换分组。音乐仍加入开始导入时选定的分组。保存前可「取消导入」撤回整批，最后保存阶段不可取消；编辑、删除、备份和恢复需等导入完成。遇到重复音乐时可跳过、仍然导入、查看已有歌曲，或取消整批。

## 播放控制

| 控件 | 用途 |
| --- | --- |
| 绑定键 | 播放当前分组中对应的音乐或片段 |
| 暂停／继续快捷键（默认 M） | 暂停或继续当前音乐；在「设置 → 快捷键」中修改或清除 |
| 主窗口空格键 | 播放所选音乐，或暂停、继续当前播放 |
| 后退／前进按钮 | 向后或向前跳转五秒 |
| 停止 | 结束当前播放 |
| 播一次即停／列表循环／单曲循环 | 设置音乐或片段播放完后的行为 |
| 速度与音量 | 调整播放速度与总音量 |

暂停快捷键不会从停止状态开始播放。若已有歌曲使用 M，升级时会保留歌曲绑定，请另设暂停快捷键。暂停键与所有分组的歌曲按键不能重复。

点击播放模式按钮，可依次切换三种模式。设置了片段的音乐按片段范围播放。

录制快捷键、输入文字或打开对话框时，音乐按键可能暂时停用，避免输入操作误触发音乐。请关闭对话框后再测试。关闭音乐快捷键总开关不会影响鼠标播放。

## 快捷键总览

打开「曲库 → 快捷键总览」，集中查看当前所选分组的歌曲绑定，以及所有分组共用的暂停／继续键。可直接修改、清除绑定，或点击「定位」返回主列表。

总览里的分组选择只用于浏览；浏览和修改其他分组的按键不会切换播放分组或打断音乐。点击「定位」会切换主曲库分组，遵循原有切换分组的播放行为。

键盘图固定在上方完整显示，表头固定，只有下方的绑定列表独立滚动。

键盘图中蓝色表示所选组合键已绑定，灰色表示在 SoundKey 中未绑定。Mac 按紧凑苹果键盘排列，底部为宽空格、Fn／地球键、修饰键和方向键；点击图中的 Control、Option、Shift、Command 查看对应组合。Windows 用修饰键开关查看对应组合；鼠标停留显示曲目，点击蓝色键可修改或清除，点击灰色键可选择音乐或暂停功能进行绑定。示意图之外的按键也会完整列在绑定列表里。总览打开时，音乐快捷键暂停触发，关闭后恢复原来的开关状态。

键盘图只显示 SoundKey 的绑定，不检测或保证其他软件、操作系统的快捷键占用。

## 整理分组

通过分组选择器切换当前快捷键使用的曲库。「管理分组」打开分组总览，可新建、重命名、切换分组和删除空分组；重命名直接在总览中编辑并保存或取消；目前不支持调整分组顺序。不同分组可以使用相同快捷键，同一分组内不允许重复绑定。

拖动音乐左侧的排序把手可调整顺序。打开「…」菜单可以修改名称与片段、移动到其他分组，或移到「最近删除」。如果目标分组已存在相同快捷键，需先解决冲突再移动。

## 只播放一段

打开「… → 名称与播放片段」，输入开始与结束时间。支持秒数或「分:秒」，例如 `30`、`0:50`。「使用当前时间」可取用这首音乐当前播放的位置。点击「播放整首」即可恢复整首播放。

片段设置只影响播放范围，不会裁剪或替换已保存的音频文件。

## 本地 MP4 转 MP3

Mac 和 Windows 都可打开「曲库 → 本地 MP4 转 MP3」，选择一个本地 `.mp4` 文件，再选择 `.mp3` 保存位置，点击「开始转换」。程序会离线提取第一个音轨，保存为 192 kbps MP3，并保留原 MP4。没有音轨的视频无法转换。

转换窗口会显示进度，转换过程中可以取消；关闭窗口也会取消任务，最终保存阶段会作为一个完整操作完成。已有目标文件需要先在保存对话框确认覆盖，且只在转换成功后替换。失败或取消会清理临时输出，并保留已有目标文件。

成功后，Mac 可点击「在 Finder 中显示」，Windows 可点击「打开保存位置」定位 MP3。需要在 SoundKey 中使用时，点击「导入本地音乐」选择保存好的 MP3。

## YouTube 与链接导入

工具栏分别提供「YouTube」和「链接导入」入口。「YouTube」会打开独立的搜索窗口，可按歌曲、歌手或关键词搜索。「试听」会在默认浏览器打开 YouTube 原始页面，不会加入曲库。「导入」会下载单个结果，保存到开始导入时选定的分组。

「链接导入」会打开独立的链接导入窗口，接受单个公开 HTTP(S) 视频页面或音频文件链接，具体网站支持取决于内置下载工具。下载内容会转换为 MP3。此流程需要联网，内容是否可用取决于来源网站。

关闭 YouTube 搜索会取消正在进行的搜索，并保留最近的关键词和结果，重新打开后可继续查看。每次只运行一个在线导入任务。下载期间搜索仍可使用，也可以关闭任一在线导入窗口，让下载继续，再从工具栏或「查看进度」重新打开；切换分组不会改变正在下载任务的目标分组。「取消下载」在下载和转换阶段可用；最终保存作为一个完整操作完成，不会显示为可取消。

此流程不支持登录、导入浏览器 Cookie、VIP 内容、付费墙或整份播放列表。能搜到结果不代表一定能下载音频。请仅导入你有权使用的内容。

## 备份、恢复与找回音乐

两端顶部的「曲库」菜单都包含「曲库备份与恢复」和「最近删除」。打开「曲库 → 曲库备份与恢复」，可导出 `.soundkeybackup` 文件。备份包含全部分组，以及音乐、名称、顺序、片段、快捷键和播放设置。建议把备份保存到应用曲库目录之外。

**从备份恢复会在确认后替换全部现有分组、音乐和播放设置**。如果要保留当前曲库，请先导出备份。Mac 与 Windows 之间可以通过备份迁移曲库；如果某些按键无法映射到另一平台，请查看恢复提示并重新设置。

移到「最近删除」前会先请求确认，完成后可点击提示中的「撤销」立即恢复。误删音乐时，打开「曲库 → 最近删除 → 恢复」。音乐优先回到原分组，原分组不存在时恢复到当前分组。如存在快捷键冲突，需要先处理，恢复不会覆盖其他绑定。「最近删除」是本地恢复存储，不能代替独立备份。

## 语言与本地数据

在「设置 → 界面语言」中选择 **English** 或 **中文**，立即切换并保存选择。新安装默认使用英文。

曲库和导入的音乐保存在本地。换电脑时请使用备份导出／恢复流程，仅复制应用不会携带曲库。卸载应用也不会自动擦除单独存放的曲库。

## 快捷键没有播放时

1. 确认当前分组和绑定键正确，并开启「音乐快捷键总开关」。
2. 关闭快捷键录制、文字输入和对话框，在主窗口先测试。
3. Mac 查看「设置 → 后台快捷键」。如果系统输入监控开关已开、SoundKey 仍提示未生效，请完全退出并重新打开「应用程序」中的版本，再点「重新检查」。
4. 后台状态就绪后，再切换到其他软件测试。系统或其他软件可能占用某些组合键，必要时更换绑定。

安装方式和当前验证范围见[安装指南](installation.zh-CN.md)与[版本验证说明](releases/1.0.2.zh-CN.md#验证范围)。
